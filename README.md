# 夜ノ街 — YORU NO MACHI

雨の夜の **東京・八重洲** を舞台にした、一人称視点のオープンワールド・クライムゲームです。ブラウザで動きます。

街は実在の地図データ（Overture Maps / OpenStreetMap 由来）から作っています。建物の形・高さ、道路の形・幅・一方通行、東京駅の高架線路、首都高の位置は、実際の八重洲周辺（約900m四方）に合わせてあります。
- **主な建物**：東京ミッドタウン八重洲、グラントウキョウ、常盤橋タワーなど。
- **主な通り**：八重洲通り、外堀通り、中央通り、鍛冶橋通り。
借金は三百万円、返済の期限は夜明け（ゲーム内 5:00、現実時間で約30分）。仕事をこなし、車を盗んで売り、警察をかわしながら金を集めます。

- **3Dモデル**：Blender（Python の `bpy`）のスクリプトで生成し、`.glb` で書き出しています。
  - **車**：横から見た輪郭をもとに形を作り、タイヤハウスをくり抜き、環境遮蔽（AO）を焼き込んでいます。
  - **車種**：セダン、パトカー、JPN TAXI 型、軽、バン、2tトラック、都営バス風。
  - **街の設備・人**：信号機、街路樹、街灯、人物、照準器付きの拳銃。
- **ゲーム本体**：Three.js で作っています。
- **画像・音**：看板の文字、窓、路面、音楽、効果音はすべてプログラムで生成しています。画像や音声のファイルは使っていません。

## 遊び方

ビルドは不要です。ローカルでHTTPサーバを立てて開きます。

```bash
cd yorunomachi
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`?q=low` を付けると、軽量モード（雨粒・人・車を減らし、解像度を下げる）で起動します。

| 照準をのぞく（ADS） | 右クリック（押している間） |

### 仕事

| 依頼主 | 仕事 | 内容 |
|---|---|---|
| ラーメン龍 | 出前 | 急ブレーキや衝突でスープがこぼれる。残量と速さで報酬が変わる |
| 金田 | 集金 | 滞納者3人を制限時間内に回る |
| 金田 | 逃がし屋 | 車で客を拾い、手配★3を振り切ってから降ろす |
| ヤマ自動車 | 車両の回収 | 指定の赤い軽自動車を盗んで運ぶ。傷が少ないほど高く売れる |

ヤマ自動車（解体屋）では、盗んだ車をいつでも売れます。パトカーは高く売れます。ただし手配中は買い取ってもらえません。

### 手配度（★）

- **上がる条件**：発砲、車両強盗、ひき逃げなどで上がります。
- **★の数**：多いほどパトカーの台数が増えます。
- **★3以上**：警官が撃ってきます。
- **下がる条件**：パトカーの視界から一定時間外れ続けると、手配が解除されます。
- **逮捕**：徒歩で止まったパトカーのそばにいると「逮捕」ゲージが溜まり、満タンで逮捕されます。
- **ペナルティ**：逮捕されると罰金、体力が尽きると治療費を払い、ゲーム内の時間も進みます。

## 画質のための工夫

- **時間帯**：タイトル画面で「夜・雨」「昼・曇り雨」「昼・晴れ」を選べます。URL に `?mode=day` / `?mode=sun` を付けても選べます。
- **晴れ**：青空と積雲、午後の日差しの影。ガラスの高層ビルは、反射の向きから青空と地上の街並みを描き分けて映します。
- **外壁の種類**：ガラスのカーテンウォール、白い格子窓のオフィス（1.5m ピッチの縦窓）、横ルーバーのオフィス、雑居ビル、赤レンガ。
- **道路**：縁石の段差と、停止線手前の各車線の矢印を実データの道路網から生成しています。
- **素材テクスチャ**：アスファルト、インターロッキング歩道、コンクリート、外壁タイルは、Blender で手続き的に作った素材を焼いたものです（`blender/bake_textures.py`）。色・法線・粗さの3枚ずつです。
- **路面標示**：白線・黄線・横断歩道・停止線は、テクスチャではなく路面に貼った実際の形状です。遠くでも潰れません。
- **窓（インテリアマッピング）**：窓の奥に部屋の箱をシェーダーで描き、見る角度で室内（床・天井・照明・棚・ブラインド）が見えます。
- **仕上げの処理**：GTAO（物の接地部分の陰り）、SMAA（輪郭のギザギザ取り）、昼は AgX の色調補正です。
  - GTAO は重いと感じたら自動で切ります。
- **車の塗装**：クリアコート（二層塗装）です。
- **人物**：`blender/person.py` で作っています。
  - 体はスキン機能＋細分化で作った、なめらかな形です。
  - 骨格とウェイトを自動で生成し、歩く・走る・立ち止まるの動きを付けています。
  - 顔（目・眉・鼻・口・耳）、髪、スーツとネクタイの男性、スカートの女性がいます。
  - 服には織り目の凹凸と、布らしい光沢（シーン）を付けています。

- **濡れた路面**：車道・白線・横断歩道・歩道タイルを実データから描いた路面テクスチャに、リアルタイムの鏡面反射、水たまり、雨の波紋を重ねています。
- **影**：月明かりのシャドウマップを使っています。プレイヤーの周囲 140m を高解像度で覆います。
- **映り込み**：起動時に街の環境マップを作り、ガラスのカーテンウォールや車体に街の明かりを映しています。
- **光**：高層ビルの航空障害灯（赤い点滅）、信号の点灯サイクル、高架を走る電車があります。
- **軽量化**：街灯などの小物は 120m 四方の区画ごとにまとめています。画面に映らない区画は描画しません。

## Mixamo の人物を使う

Mixamo（https://www.mixamo.com）の人物と動きを変換して、歩行者として使えます。

1. **人物**：Characters から選び、FBX Binary、T-pose でダウンロードします。
2. **動き**：Animations で「In Place」にチェックを入れ、FBX Binary、Without Skin でダウンロードします。
   - 使う動き：Walk W/ Briefcase、Running、Idle など
3. ダウンロードしたファイルを `assets/source/mixamo/` に置き、`python blender/mixamo.py` を実行します。
   - 骨の名前をそろえ、ポリゴンを約9,000三角形に間引き、テクスチャを1024pxに縮めて、`assets/models/mx_*.glb` を出力します。
   - ファイル名から動きの種類を判断します（walk / run / idle / walk_turn）。
   - 前へ進む動き（ルートモーション）は消して、その場で足踏みする動きにします。

`mx_*.glb` があれば、歩行者はそれを使います。無ければ Blender で作った人物を使います。鞄を持って歩く動きの人には、ゲーム側でビジネスバッグを持たせています。

## 一人称の右腕

`blender/fp_arm.py` で、Mixamo の人物（Ch33）から右の前腕と手だけを切り出しています。スーツの袖と実写風の手のテクスチャを、そのまま使っています。指の骨を曲げて拳銃を握る形にし、そのポーズのまま固めて `assets/models/fp_arm.glb` に書き出します。

```bash
AXIS=X python blender/fp_arm.py assets/source/mixamo/Ch33_nonPBR.fbx
```

## Poly Haven の素材を使う

Poly Haven（https://polyhaven.com、CC0）の `.blend` を `blender/polyhaven.py` で glb に変換しています。

- **拳銃**：Service Pistol。一人称の拳銃として使っています。照準器の高さは自動で合わせます。
- **金網フェンス**：Modular Chainlink Fence。街の空き地に置いた工事現場の囲いに使っています。

```bash
python blender/polyhaven.py <.blend> ph_pistol service_pistol_pistol_a,service_pistol_slide_a,service_pistol_hammer_a,service_pistol_trigger_a 2048
python blender/polyhaven.py <.blend> ph_fence modular_chainlink_fence_double,modular_chainlink_fence_post 1024
```

テクスチャは WebP に縮めます（拳銃は 23MB → 1.7MB）。

## 八重洲の地図データを作り直す

```bash
pip install pyarrow shapely pillow
python tools/fetch_overture.py theme=buildings/type=building 139.7620,35.6745,139.7780,35.6860 tools/data/bld.json
python tools/fetch_overture.py theme=transportation/type=segment 139.7600,35.6730,139.7800,35.6875 tools/data/road.json
python tools/build_map.py        # assets/map/ に yaesu.json・路面テクスチャ・ミニマップを出力
```

- **別の街で作る**：緯度経度の範囲と、`build_map.py` の原点（`LAT0`, `LON0`）を変えます。
- **高さのデータが無い有名ビル**：`OVERRIDE` で公開されている高さを補っています。
  - 東京ミッドタウン八重洲：240m
  - グラントウキョウノースタワー：205m

## Blender でアセットを作り直す

```bash
pip install bpy==4.5.14          # Python 3.11 用の Blender モジュール
python blender/build_assets.py            # assets/models/*.glb を再生成
python blender/build_assets.py --preview  # blender/previews/*.png も出力（Cycles CPU で描画）
```

Blender 本体からも実行できます: `blender -b -P blender/build_assets.py`

### Blender とゲーム側の決まりごと

- **向き**：モデルは Blender の +Y 方向を「前」にして作ります。書き出すと three.js 側では -Z が前になります。
- **名前**：部位はオブジェクト名で区別し、ゲーム側では名前で参照します。
  - `Body*`：塗装色を差し替える部分
  - `Wheel_FL/FR/RL/RR`：回転の中心になる空のオブジェクト（エンプティ）
  - `Light_Tail`：ブレーキ時に光る部分
  - `Light_Siren`：赤と青に点滅する部分
- **自分でモデリングした場合**：手でモデリングしたモデルに差し替えるときも、この名前の付け方を守れば、そのまま動きます。

## Unreal Engine へ移植する場合

- **モデル**：Blender のスクリプトは FBX でも書き出せます（`bpy.ops.export_scene.fbx`）。同じ手順で Unreal 用のアセットを作れます。
- **ロジック**：ゲームの処理（交通AI、手配度、仕事の状態の管理）は描画から切り離して書いてあります。そのため Blueprint や C++ に移し替えやすい構成です。
- **置き換える部分**：
  - 濡れた路面の反射 → Lumen の反射
  - 雨 → Niagara
  - 手続き生成しているネオン看板 → Unreal のマテリアル
